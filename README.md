# NOX

an AI productivity assistant that won't let you procrastinate.

NOX watches what you do and keeps you on task. it has exactly one rule:

> **never let the user quit before the task is finished.**

## features
- focus timer + task lock
- distraction blocker
- login page
- autosave (`save_progress.py`)
- hourly productivity tracking (`productivity_tracker.xlsx`)
- logs everything (`nox.db`)
